Замена монолитного Apache Camel ESB. Event-driven интеграция доменов Клиники / Финтех / ИИ через асинхронные топики без прямых зависимостей между сервисами. Обеспечивает подключение новых партнёров (фармацевтика, медоборудование) без изменения существующих доменов. Kafka Connect используется для стриминга событий в Data Lake.
