Real-time обработка потоков событий. Перспективен для антифрода в финтехе и мониторинга телеметрии медоборудования в режиме реального времени. На текущем горизонте (год) достаточно пакетной обработки через Airflow. Решение по переходу принимается после стабилизации платформы данных.
