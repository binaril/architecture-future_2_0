Колоночный аналитический DWH. Замена SQL Server 2008 для OLAP-нагрузки. Сокращает время формирования сложных аналитических отчётов с нескольких часов до 5–30 минут. Разделяет операционный и аналитический трафик, устраняя конкуренцию за ресурсы с клиническими операциями.
